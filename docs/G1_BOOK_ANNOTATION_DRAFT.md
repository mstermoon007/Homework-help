> 数据文件：`docs/g1-book-annotation-draft.json`（结构化，按三重视角标注，**不含模块字段**）。
> 对照基准：人教 2024 新课标一上/一下教材 + 2022 课标四大领域 + G1 kp.concept 既有定位文本。

## 1. 组织架构

```
教材定位（book 册 + unit 单元）
   └─ 知识点（kp）
         └─ 类别（category：数与代数 / 图形与几何 / 统计与概率 / 常见的量 / 综合与实践）
```

每个知识点携带三个组织属性：`book`（上/下册）、`unit`（教材单元）、`category`（知识领域类别）。

## 5. 模块字段删除说明

- G1 53 个 kp 均**无 moduleId 字段**（已核验），模块归属仅由容器决定。
- 本草案以 `book/unit/category` 三重视角组织，**不含模块字段**。
- 数据容器迁移（模块容器 → 册/单元容器）属独立工程（全仓库 106 文件引用 moduleId），建议与草案应用分开走。
