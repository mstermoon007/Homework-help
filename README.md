# Homework-help
# 📝 小学练习本

一个**完全免费、无广告、无弹窗**的网页练习工具，专为家长辅导孩子学习设计。  
支持一年级到三年级，题型紧贴人教版教材和常见练习册。只需选好年级、题量，点击按钮即可自动生成练习题，并支持在线作答、即时批改、错题纠正与打印输出。

---

## ✨ 核心特点

- 🆓 **永久免费** — 无任何收费项目，无需注册登录
- 🚫 **纯净体验** — 无广告、无弹窗、无诱导分享，专注学习本身
- 📚 **教材同步** — 题型基于人教版教材与主流练习册设计，覆盖一年级至三年级
- 🎲 **智能出题** — 随机生成题目，每次练习都不重样，有效避免机械记忆
- ✅ **即时批改** — 一键检查答案，每题标对错，给出得分、正确率与鼓励语，错题直接展示正确答案
- 👀 **答案显隐** — 可随时显示或隐藏标准答案，方便自查或作为题卡使用
- ⏱️ **自动计时** — 题目生成后自动开始计时，提交答案时停止，帮助掌握做题速度
- 🖨️ **纯净打印** — 打印时自动隐藏所有按钮和无关元素，仅保留题目，生成 A4 友好的练习卷
- 🔒 **隐私安全** — 纯前端运行，无需服务器，题目和孩子作答数据不上传

## 🚀 快速开始

### 在线使用
访问 [https://你的域名或GitHub Pages地址]（示例）即可直接使用，无需安装。

### 本地运行
项目为纯静态网页，无需构建工具或后端环境。

```bash
# 克隆仓库
git clone https://github.com/你的用户名/primary-practice-book.git

# 进入目录
cd primary-practice-book

# 直接用浏览器打开 index.html（或使用本地服务器）
# 例如使用 Python 的简单 HTTP 服务（可选）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

直接双击 `index.html` 也能运行，但推荐使用本地服务器以避免某些浏览器的安全限制。

## 🧩 功能预览

*（以下为功能示意图，实际界面可能有所不同）*

1. **选择年级**  
   下拉菜单选中一年级 / 二年级 / 三年级，题目难度与知识点自动匹配。

2. **设定题量**  
   快捷选择 5 / 10 / 15 / 20 题，或自定义 1~50 范围内的任意数量。

3. **生成练习题**  
   点击 🎲 **生成练习题** 按钮，系统随机出题并展示答题区，计时器同步启动。

4. **在线作答**  
   在输入框中填写答案，支持键盘快速切换题目。

5. **批改与反馈**  
   点击 ✅ **检查答案**：  
   - 每题显示 ✓ 或 ✗，并标注正确率  
   - 自动显示总分和鼓励语（如“太棒了！”“继续加油！”）  
   - 错题区直接给出正确答案，方便订正

6. **答案显示控制**  
   使用 **显示答案 / 隐藏答案** 开关，可作为题卡让学生自行核对。

7. **打印练习卷**  
   点击 🖨️ **打印** 按钮，页面将自动：  
   - 隐藏所有操作按钮、批改结果、计时器等  
   - 保留标题、题目序号和题目内容  
   - 调整为适合 A4 纸打印的排版，直接调用浏览器打印

## 🧑‍🏫 使用说明

### 出题规则
- **一年级**：20以内加减法、简单的文字题、数一数等，紧跟教材进度。
- **二年级**：表内乘除法、100以内加减混合、长度单位、认识时间等。
- **三年级**：万以内加减、多位数乘一位数、分数初步、周长计算等。
题目由题库随机抽取组合，保证每次生成顺序和内容均不同。

### 自定义题库
如需调整知识点或扩充年级，可编辑 `js/questionBank.js` 文件，按照现有格式添加题型。无需修改核心逻辑。

### 打印技巧
- 点击打印后，若浏览器弹出预览，可设置边距为“无”，缩放“适合页面宽度”，以获得最佳效果。
- 生成试卷时建议题量选择 10 或 20 题，刚好填满一页 A4。
